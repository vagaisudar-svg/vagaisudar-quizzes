SQL Components Overview
DDL – CREATE, ALTER, DROP, TRUNCATE DML – INSERT, UPDATE, DELETE DQL – SELECT DCL – GRANT, REVOKE TCL – COMMIT, ROLLBACK, SAVEPOINT
DDL defines structure. DML manipulates data. DQL queries data. DCL controls access. TCL manages transactions.
