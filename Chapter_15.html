15.1 Introduction

A database is an organised collection of related data. A Database Management System (DBMS) is software that manages these databases. A Relational DBMS (RDBMS) stores data in tables (rows and columns).

Python's built-in sqlite3 module lets you create and interact with SQLite databases without any extra installation. SQLite stores the entire database in a single .db file.

In this chapter, we create Academy.db with a Student table to practise all SQL operations.

The sqlite3 module is part of Python's standard library — no pip install needed.

15.2 SQLite

Every Python-SQLite program follows the same three steps:

1

Connect

Open (or create) the .db file with sqlite3.connect()

2

Cursor

Create a cursor object — it executes SQL and holds results

3

Execute & Commit

Run SQL with execute(), save changes with commit(), then close()

Python 
import sqlite3
conn = sqlite3.connect("Academy.db")   # creates file if not exists
cursor = conn.cursor()
# ... execute SQL ...
conn.commit()
conn.close()
Tip: sqlite3.connect(":memory:") creates a temporary in-memory database — great for testing.

15.3 Creating Academy.db and the Student Table

15.3.1 CREATE TABLE

The Student table stores roll number, name, section, gender, marks and date of birth:

Python – Ex 15.3.1 
import sqlite3
conn = sqlite3.connect("Academy.db")
cursor = conn.cursor()
sql = """CREATE TABLE Student(
        Rollno INTEGER PRIMARY KEY,
        Sname VARCHAR(20),
        Section VARCHAR(5),
        Gender VARCHAR(5),
        Mark DECIMAL(5,2),
        DOB DATE)"""
cursor.execute(sql)
conn.commit()
conn.close()
print("Table created")
INTEGER PRIMARY KEY in SQLite automatically acts as an auto-increment column — if you omit the value during INSERT, SQLite assigns the next available integer.

15.3.2 INSERT Records

Method 1 – Direct values:

Python – Ex 15.3.2 (single row) 
import sqlite3
conn = sqlite3.connect("Academy.db")
cursor = conn.cursor()
cursor.execute("INSERT INTO Student VALUES(1,'Akshay','B','M',87.8,'2001-12-12')")
conn.commit()
conn.close()

Method 2 – Loop with format string (textbook approach):

Python – Ex 15.3.2 (loop) 
import sqlite3
conn = sqlite3.connect("Academy.db")
cursor = conn.cursor()
records = [
    (1,'Akshay','B','M',87.8,'2001-12-12'),
    (2,'Aravind','A','M',92.5,'2000-08-17'),
    (3,'BASKAR','C','M',75.2,'1998-05-17'),
    (4,'SAJINI','A','F',95.6,'2002-11-01'),
    (5,'VARUN','B','M',80.6,'2001-03-14'),
    (6,'PRIYA','A','F',98.6,'2002-01-01'),
    (7,'TARUN','D','M',62.3,'1999-02-01'),
]
format_str = "INSERT INTO Student VALUES({0},'{1}','{2}','{3}',{4},'{5}')"
for rec in records:                       # ← execute must be INSIDE the loop
    sql_command = format_str.format(*rec)
    cursor.execute(sql_command)
conn.commit()
conn.close()
Note: The textbook loop example sometimes places cursor.execute() outside the loop body — that only inserts the last record. The corrected version above keeps execute inside the loop.
GOOD PRACTICE Use ? placeholders instead of format() for SQL — they prevent SQL injection: cursor.executemany("INSERT INTO Student VALUES(?,?,?,?,?,?)", records)

15.4 SELECT Statement

The SELECT statement retrieves rows from a table. There are three fetch methods:

MethodReturnsUse when
fetchall()List of all rows (tuples)Small result sets

import sqlite3

15.4.2 Clauses

DISTINCT – removes duplicate values:

SQL 
SELECT DISTINCT Section FROM Student
('B',) ('A',) ('C',) ('D',)

WHERE – filter rows:

SQL 
SELECT * FROM Student WHERE Mark > 90
(2, 'Aravind', 'A', 'M', 92.5, '2000-08-17') (4, 'SAJINI', 'A', 'F', 95.6, '2002-11-01') (6, 'PRIYA', 'A', 'F', 98.6, '2002-01-01')

GROUP BY – group rows sharing a value:

SQL 
SELECT Section, COUNT(*) FROM Student GROUP BY Section
('A', 3) ('B', 2) ('C', 1) ('D', 1)

ORDER BY – sort results (ASC default, DESC for reverse):

SQL 
SELECT * FROM Student ORDER BY Mark DESC

HAVING – filter groups (applied after GROUP BY):

SQL 
SELECT Section, COUNT(*) FROM Student
GROUP BY Section HAVING COUNT(*) > 1
('A', 3) ('B', 2)
WHERE vs HAVING: WHERE filters individual rows before grouping. HAVING filters groups after aggregation. Both can be used together:
SELECT Section, AVG(Mark) FROM Student WHERE Gender='M' GROUP BY Section HAVING AVG(Mark)>80

15.6 Date Column Querying

SQLite stores dates as text in ISO 8601 format (YYYY-MM-DD). String comparison works correctly for this format, so > and < operators give the right chronological order.

Python – Ex 15.6 
cursor.execute("SELECT Sname,DOB FROM Student WHERE DOB<'2001-01-01'")
for row in cursor.fetchall(): print(row)
('Aravind', '2000-08-17') ('BASKAR', '1998-05-17') ('TARUN', '1999-02-01')
GOOD PRACTICE Always store dates as YYYY-MM-DD (ISO 8601). The textbook's GAMES table uses MM-DD-YYYY which breaks date comparisons — see Hands-on section.

15.8 UPDATE

UPDATE changes existing rows. Always use WHERE to target specific rows — without it, every row is changed.

Python – Ex 15.8 
import sqlite3
conn = sqlite3.connect("Academy.db")
cursor = conn.cursor()
cursor.execute("UPDATE Student SET Mark=90.0 WHERE Sname='Akshay'")
conn.commit()
print("Rows changed:", conn.total_changes)
conn.close()
Rows changed: 1
conn.total_changes returns the total number of rows modified since the connection was opened.

15.9 DELETE

DELETE removes rows. Without WHERE, it deletes all rows from the table.

Python – Ex 15.9 
cursor.execute("DELETE FROM Student WHERE Mark<70")
conn.commit()
Always test your WHERE clause with SELECT before running DELETE or UPDATE — you can't easily undo a committed delete.

15.10 User Input with ? Placeholders

Instead of building SQL strings with format(), use parameterised queries. The ? placeholder lets SQLite safely handle user input and prevents SQL injection.

Python – Ex 15.10 
import sqlite3
conn = sqlite3.connect("Academy.db")
cursor = conn.cursor()
name = input("Enter name: ")
cursor.execute("SELECT * FROM Student WHERE Sname=?", (name,))   # tuple!
for row in cursor.fetchall(): print(row)
conn.close()
Textbook Fix FIX Ex 15.10-1 has DROP TABLE person which fails on the first run (table doesn't exist yet). Use DROP TABLE IF EXISTS person. The example also lacks commit() and close().
GOOD PRACTICE Always use ? placeholders for user input — they protect against SQL injection. Never concatenate user input directly into SQL strings.

15.11 Multiple Table Querying

To query two tables together, list both in FROM and specify how they relate in WHERE. This is an implicit (comma) JOIN.

The Appointment table: (Appno, Duty, Rollno)

Python – Ex 15.11 
import sqlite3
conn = sqlite3.connect("Academy.db")
cursor = conn.cursor()
cursor.execute("""SELECT Student.Sname, Appointment.Duty
               FROM Student, Appointment
               WHERE Student.Rollno = Appointment.Rollno""")
for row in cursor.fetchall(): print(row)
conn.close()
('Aravind', 'Prefect') ('BASKAR', 'Secretary')
Textbook Fix FIX Ex 15.11-1 CREATE TABLE statement has typo "rollnointprimarkey,Dutyvarchar(10)". Correct SQL:
Rollno INTEGER PRIMARY KEY, Duty VARCHAR(10), age INT
Also, DROP TABLE Appointment fails on first run — use DROP TABLE IF EXISTS Appointment.

You can also list all tables in the database using sqlite_master:

Python – List tables 
cursor.execute("SELECT name FROM sqlite_master WHERE type='table'")
print(cursor.fetchall())
[('Student',), ('Appointment',)]

15.12 CSV Integration

Python's csv module exports query results to a CSV file.

Python – Ex 15.12 
import sqlite3, csv
conn = sqlite3.connect("Academy.db")
cursor = conn.cursor()
cursor.execute("SELECT * FROM Student ORDER BY Gender DESC, Sname")
rows = cursor.fetchall()
with open('c:/pyprg/sql.csv', 'w', newline='') as f:   # newline='' is required
    writer = csv.writer(f)
    writer.writerow([col[0] for col in cursor.description])  # header
    writer.writerows(rows)
conn.close()
Textbook Fix FIX The textbook prints open('c:/pyprg/sql.csv','w, newline= ' ') — the quote is placed inside the string, making newline part of the filename. The correct syntax has newline='' as a separate keyword argument (see above).
newline='' is required on Windows to prevent csv.writer from adding extra blank lines between rows.

Glossary

DatabaseAn organised collection of related structured data
DBMSSoftware that creates, manages and secures databases (e.g. SQLite, MySQL)
SQLiteA lightweight, file-based RDBMS built into Python's standard library
ConnectionThe object returned by sqlite3.connect(); represents the open database file
CursorObject that executes SQL statements and holds query results
Commitconn.commit() — saves all pending changes permanently to disk
Primary KeyA column whose value uniquely identifies each row; no two rows may share it
TupleEach row returned by fetchall/fetchone is a Python tuple
Placeholder (?)A ? in SQL that SQLite replaces safely with a parameter value
Aggregate FunctionA function that computes a single result from many rows: COUNT, SUM, AVG, MAX, MIN
sqlite_masterBuilt-in SQLite table listing all tables, indexes and views in the database
CSVComma-Separated Values — a plain-text format for tabular data, readable by Excel

Points to Remember

  • Python's sqlite3 module is part of the standard library — no installation needed
  • The sequence is: connect → cursor → execute → commit → close
  • INTEGER PRIMARY KEY auto-increments in SQLite
  • fetchall() returns all rows; fetchone() returns the next row; fetchmany(n) returns next n rows
  • cursor.description gives column names after a SELECT
  • WHERE filters rows before grouping; HAVING filters groups after aggregation — both can be used together
  • Aggregate functions: COUNT, AVG, SUM, MAX, MIN — used with SELECT or HAVING
  • Always use WHERE with UPDATE and DELETE — without it, every row is affected
  • Use ? placeholders (parameterised queries) instead of string formatting for user input
  • Store dates in YYYY-MM-DD format for correct sorting
  • conn.total_changes returns rows modified since connection opened
  • Use newline='' when opening CSV files on Windows to avoid extra blank lines
  • sqlite_master lists all tables: SELECT name FROM sqlite_master WHERE type='table'
  • For multi-table queries, link tables via a WHERE condition on shared columns (implicit JOIN)
