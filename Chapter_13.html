13.1 Introduction

Python's built-in csv module for reading and writing CSV files

A CSV (Comma-Separated Values) file is a human-readable text file where each line has fields separated by commas or another delimiter character. The csv module in Python enables you to parse CSV files easily without writing complex parsing logic yourself.

📌 Note

The CSV module is part of Python's standard library — no installation needed. Just import csv.

CSV files are widely used for data exchange between applications — spreadsheets, databases, and web services all export/import CSV. Python provides two main approaches:

  • csv.reader() / csv.writer() — works with lists and tuples
  • csv.DictReader() / csv.DictWriter() — works with dictionaries
💡 Do You Know?

A CSV file is also known as a Flat File.

13.3 Purpose of CSV Files

Why CSV is the universal data exchange format

CSV is a simple file format for representing tabular data (rows and columns) as plain text. It is one of the most common formats for exchanging data between different programs and systems.

Common Use Cases

  • Exporting data from databases and spreadsheets
  • Importing data into applications and analytics tools
  • Sharing datasets between systems with different software
  • Data science and machine learning datasets
  • Logging and reporting
💡 Do You Know?

By default, CSV files open automatically in Excel on Windows, which is why many users don't realize they're plain text files.

✅ Tip

The CSV library in Python contains objects and code to read, write, and process data from and to CSV files.

13.4 CSV File Formats

Different types of CSV and the 7 formatting rules

13.4.1 Normal CSV ▼

A basic CSV with headers on the first row and values separated by commas:

Topic1,Topic2,Topic3
one,two,three
Example1,Example2,Example3
13.4.2 CSV with Commas in Data ▼

When a field contains a comma, enclose that field in double quotes:

RollNo, Name, Address
12101, Nivetha, "Mylapore, Chennai"
12102, Lavanya, "Adyar, Chennai"
12103, Ram, "Gopalapuram, Chennai"

The address field is quoted because it contains a comma.

13.4.3 CSV with Double Quotes in Data ▼

When a field contains double quotes, use two consecutive double quotes to represent a single quote:

RollNo, Name, FavoriteSports, Address
12101, Nivetha, """ Cricket "","" Football """, Mylapore chennai
12102, Lavanya, """ Basketball "","" Cricket """, Adyar chennai
12103, Ram, """ Soccer"","" Hockey""", Gopalapuram chennai
13.4.4 The 7 Rules for CSV Formatting ▼
  1. Each record is on a separate line, delimited by a line break (CRLF = Carriage Return and Line Feed)
  2. The last record in the file may or may not have an ending line break
  3. There may be an optional header line appearing as the first line with the same format as normal record lines
  4. Spaces are considered part of a field and should not be ignored; the last field in a record must not be followed by a comma
  5. Each field may or may not be enclosed in double quotes; if not enclosed, double quotes may not appear inside the fields
  6. Fields containing line breaks (CRLF), double quotes, and commas should be enclosed in double-quotes
  7. If double-quotes are used to enclose fields, then a double-quote appearing inside a field must be preceded by another double quote
📌 Note

Empty fields: , , White — the two leading commas are required to represent two empty fields before "White".

csv.reader()

Reading CSV files with Python's built-in csv module

The csv.reader() function returns a reader object that iterates over lines in a CSV file. Each row is returned as a list of strings.

Program 13.6.1.1.1 — Default comma delimiter (sample1.csv) Program 
import csv
with open('c:\\pyprg\\sample1.csv', 'r', newline='') as F:
    reader = csv.reader(F)
    for row in reader:
        print(row)
    F.close()
Output
['SNO', 'NAME', 'CITY'] ['1', 'Arjun', 'Chennai'] ['2', 'Priya', 'Madurai']

Using register_dialect() and skipinitialspace

When CSV has spaces after delimiters, use skipinitialspace=True to strip them automatically.

Program 13.6.1.1.2 — skipinitialspace (sample2.csv) Program 
import csv
csv.register_dialect('myDialect', delimiter=',', skipinitialspace=True)
F = open('c:\\pyprg\\sample2.csv', 'r')
reader = csv.reader(F, dialect='myDialect')
for row in reader:
    print(row)
F.close()
Output — sample2.csv: Topic1, Topic2, Topic3 / one, two, three / Example1, Example2, Example3
['Topic1', 'Topic2', 'Topic3'] ['one', 'two', 'three'] ['Example1', 'Example2', 'Example3']
📌 Note

skipinitialspace=True removes whitespaces immediately after the delimiter. Without it, " two" (with space) would remain as a string with the leading space.

import csv

Reading Specific Columns

Accessing individual fields by index

Each row returned by csv.reader() is a list. Use index notation (row[0], row[3]) to access specific columns.

Program 13.6.2 — Read specific columns (Item Name and Profit) Program 
import csv
f = open("c:\\pyprg\\ch13sample5.csv", 'r')
readFile = csv.reader(f)
for col in readFile:
    print(col[0], col[3])  # Item Name (col 0), Profit (col 3)
f.close()
Output
Item Name Profit Keyboard 1152 Monitor 10400 Mouse 2000
📌 Note

Column indices start at 0. The header row is also printed unless you skip it with next(reader).

Read CSV into a List

Storing all rows in a Python list for in-memory processing

Program 13.6.3 — Read all rows into a list Program 
import csv
inFile = 'c:\\pyprg\\sample.csv'
F = open(inFile, 'r')
reader = csv.reader(F)
arrayValue = []
for row in reader:
    arrayValue.append(row)
    print(row)
F.close()

After this loop, arrayValue is a list of lists — each inner list is one CSV row. This allows random access: arrayValue[0] gives the header row, arrayValue[1][2] gives the value in row 1, column 2.

Sorting CSV Data

Using next(), sort(), and operator.itemgetter() to sort columns

Program 13.6.4 — Sort a column, skip header with next() Program 
import csv
inFile = 'c:\\pyprg\\sample6.csv'
F = open(inFile, 'r')
reader = csv.reader(F)
next(reader)  # skip the header row
arrayValue = []
a = int(input("Enter the column number between 0 to 3:-"))
for row in reader:
    arrayValue.append(row[a])
arrayValue.sort(reverse=True)
for row in arrayValue:
    print(row)
F.close()
📌 Note

next(reader) advances the iterator by one row, effectively skipping the header. After next(reader), the loop starts from the second row.

Program 13.6.5 — Sort by column with operator.itemgetter() Program 
import csv, operator
data = csv.reader(open('c:\\pyprg\\sample8.csv'))
next(data)  # omit header
sortedlist = sorted(data, key=operator.itemgetter(1))
for row in sortedlist:
    print(row)
sample8.csv: ItemName,Quantity / Keyboard,48 / Monitor,52 / Mouse,20
['Mouse ', '20'] ['Keyboard', '48'] ['Monitor', '52']
✅ Tip

operator.itemgetter() can sort by more than one column: operator.itemgetter(1, 2) sorts first by column 1, then column 2 for ties.

csv.DictReader

Reading CSV rows as dictionaries — fieldnames become keys

csv.DictReader reads the first row as field names and maps each subsequent row to an OrderedDict. Access values by column name instead of index.

Program 13.6.6 — DictReader with default comma delimiter Program 
import csv
filename = 'c:\\pyprg\\sample8.csv'
input_file = csv.DictReader(open(filename, 'r'))
for row in input_file:
    print(dict(row))
Output
{'ItemName ': 'Keyboard ', 'Quantity': '48'} {'ItemName ': 'Monitor', 'Quantity': '52'} {'ItemName ': 'Mouse ', 'Quantity': '20'}
Program 13.6.7 — DictReader with pipe delimiter Program 
import csv
csv.register_dialect('myDialect', delimiter='|', skipinitialspace=True)
filename = 'c:\\pyprg\\ch13\\sample8.csv'
with open(filename, 'r', newline='') as csvfile:
    reader = csv.DictReader(csvfile, dialect='myDialect')
    for row in reader:
        print(dict(row))
    csvfile.close()
sample8.csv (pipe): ItemName|Quantity / Keyboard|48 / Monitor|52 / Mouse|20
{'ItemName': 'Keyboard', 'Quantity': '48'} {'ItemName': 'Monitor', 'Quantity': '52'} {'ItemName': 'Mouse', 'Quantity': '20'}
📌 Note

DictReader creates an object that maps data to a dictionary. The dict() function is used to print in dictionary format. Unlike csv.reader which works with lists, DictReader works with dictionaries.

csv.writer()

Writing data to CSV files row by row or all at once

csv.writer() returns a writer object that converts data into delimited strings and writes them to a file object. Use writerow() for one row or writerows() for multiple rows.

Program 13.7.1 — Write multiple rows (Pupil.csv) Program 
import csv
csvData = [['Student', 'Age'], ['Dhanush', 17],
           ['Kalyani', 18], ['Ram', 15]]
with open('c:\\pyprg\\ch13\\Pupil.csv', 'w', newline='') as CF:
    writer = csv.writer(CF)
    writer.writerows(csvData)
    CF.close()
Pupil.csv contents
Student,Age Dhanush,17 Kalyani,18 Ram,15
📌 Note

Always open files for writing with newline='' on Windows to prevent extra blank lines. writerow() writes one row at a time; writerows() writes all rows at once from a list of lists.

Modifying and Appending CSV

Read → modify → write back; append new rows

Program 13.7.2 — Modify a row in student.csv Program 
import csv
with open('student.csv', 'r', newline='') as readFile:
    reader = csv.reader(readFile)
    lines = list(reader)
    lines[3] = ['3', 'Meena', 'Bangalore']  # modify row index 3
with open('student.csv', 'w') as writeFile:
    writer = csv.writer(writeFile)
    writer.writerows(lines)
readFile.close()
writeFile.close()
student.csv after modification
Roll No,Name,City 1,Harshini,Chennai 2,Adhith,Mumbai 3,Meena,Bangalore ← was Dhuruv 4,Krishna,Tiruchy 5,Venkat,Madurai
Program 13.7.2.1 — Append a new row Program 
import csv
row = ['6', 'Sajini', 'Madurai']
with open('student.csv', 'a', newline='') as CF:
    writer = csv.writer(CF)
    writer.writerow(row)
    CF.close()
✅ Tip

Adding a new row at the end of a file is called appending a row. Use mode 'a' (append) — it doesn't overwrite existing data.

csv.DictWriter

Writing dictionaries to CSV with named fields

csv.DictWriter takes a list of dictionaries and writes them to a CSV file. You must specify fieldnames — the order of columns in the output. Use writeheader() to write the header row.

Program 13.7.7 — DictWriter (peak.csv) Program 
import csv
data = [{'MOUNTAIN':'Everest','HEIGHT':'8848'},
        {'MOUNTAIN':'Anamudi','HEIGHT':'2695'},
        {'MOUNTAIN':'Kanchenjunga','HEIGHT':'8586'}]
fields = ['MOUNTAIN','HEIGHT']
with open('c:\\pyprg\\ch13\\peak.csv', 'w', newline='') as CF:
    w = csv.DictWriter(CF, fieldnames=fields)
    w.writeheader()
    w.writerows(data)
    print("writing completed")
    CF.close()
peak.csv
MOUNTAIN,HEIGHT Everest,8848 Anamudi,2695 Kanchenjunga,8586
Program 13.7.7.1 — DictWriter with dialect (grade.csv) Program 
import csv
fieldnames = ['Grade','Name']
csv.register_dialect('myDialect', delimiter='|', quoting=csv.QUOTE_ALL)
with open('c:\\pyprg\\ch13\\grade.csv', 'w', newline='') as csvfile:
    writer = csv.DictWriter(csvfile, fieldnames=fieldnames, dialect='myDialect')
    writer.writeheader()
    writer.writerows([{'Grade':'B','Name':'Anu'},
                       {'Grade':'A','Name':'Beena'},
                       {'Grade':'C','Name':'Tarun'}])
    print("writing completed")
grade.csv
"Grade"|"Name" "B"|"Anu" "A"|"Beena" "C"|"Tarun"
📌 Note

csv.reader and csv.writer work with list/tuple. csv.DictReader and csv.DictWriter work with dictionaries and take an additional fieldnames argument.

Part I — Choose the Best Answer (1 Mark)

1. A CSV file is also known as _____ ▼

Answer: (A) Flat File — CSV files store data in a flat, plain-text structure without any hierarchy, hence the name.

2. Each record is delimited by _____ ▼

Answer: (D) Carriage Return and Line Feed (CRLF) — In CSV format, each record (row) is separated by CRLF (\r\n).

3. _____ module is used to read CSV files in Python ▼

Answer: (B) csv — Python's built-in csv module provides all functionality for reading and writing CSV files.

4. _____ mode is used to open non-text files ▼

Answer: (B) Binary mode ('b') — Non-text files like images and executables must be opened in binary mode.

5. _____ function is used to skip the first row (header) ▼

Answer: (A) next() — Calling next(reader) advances the reader iterator by one step, skipping the header row.

6. _____ is used to customize line endings in CSV ▼

Answer: (A) lineterminator — The lineterminator dialect parameter sets the character(s) used to end each row.

7. What is the output of DictReader with next() skipping first row? ▼

Answer: (B) mumbai,andheri — When next(d) skips the first row (chennai,mylapore), only the second row (mumbai,andheri) is printed.

8. _____ reads CSV rows as dictionaries ▼

Answer: (D) DictReader() — csv.DictReader() maps each row to a dictionary where keys are the header field names.

9. Opening an existing file in write mode ('w') causes _____ ▼

Answer: (C) Modification (truncation) — Opening in 'w' mode truncates (empties) the file and starts fresh, effectively modifying/replacing it.

10. With lineterminator='\n', Exam, Quarterly, Halfyearly appear on _____ ▼

Answer: (C) Separate lines — With lineterminator='\n', each row ends with a newline character, so each item appears on its own line: Exam\nQuarterly\nHalfyearly.

Part II — Short Answers (2 Marks)

What is a CSV file? ▼

A CSV (Comma-Separated Values) file is a human-readable plain text file where each line represents a record and fields within each record are separated by commas (or another delimiter). It is widely used for exchanging tabular data between applications.

Two ways to read a CSV file in Python ▼
  1. csv.reader() — Reads rows as lists of strings
  2. csv.DictReader() — Reads rows as dictionaries with field names as keys
Default file modes in Python ▼

The default mode for open() is 'r' (read) and 't' (text mode). So open('file.csv') is equivalent to open('file.csv', 'rt').

Use of next() with csv.reader ▼

next(reader) advances the iterator by one position. When used after creating a reader object, it skips the first row (usually the header row) so that the subsequent loop processes only data rows.

How to sort by more than one column using itemgetter? ▼
sorted(data, key=operator.itemgetter(1, 2))

Pass multiple indices to itemgetter(). This sorts primarily by column 1, and for rows where column 1 is equal, sorts by column 2.

Part III — Explain in Detail (3 Marks)

Explain the open() function with its modes ▼

The open(filename, mode) function opens a file and returns a file object. Common modes: 'r' (read), 'w' (write/truncate), 'a' (append), 'x' (exclusive create), 'b' (binary), 't' (text, default), '+' (read+write). Modes can be combined: 'rb', 'w+'.

How to modify an existing CSV file? ▼
  1. Open file in read mode, read all rows into a list with list(reader)
  2. Modify the specific row: lines[index] = [new, values]
  3. Open the same file in write mode (this truncates it)
  4. Write all rows back with writer.writerows(lines)
