Introduction to PHP

PHP tags · Variables · Data types · Echo · Comments

PHP குறிச்சொற்கள் · மாறிகள் · தரவு வகைகள் · Echo · கருத்துரைகள்

📖 What is PHP?

PHP stands for PHP: Hypertext Preprocessor (recursive acronym). It is a widely-used, open-source server-side scripting language designed primarily for web development.

  • Created by Rasmus Lerdorf in 1994
  • Server-side scripting: code runs on the server, not the browser
  • Interpreted language (no compilation needed)
  • Embedded in HTML pages
  • Free and open-source
  • File extension: .php
Easy Explanation 💡 Think of PHP like a chef in a restaurant kitchen. The customer (browser) orders food (requests a page). The chef (PHP server) prepares it and sends the finished dish (HTML) to the customer. The customer never sees the kitchen — only the final result.
📝 Exam Point PHP = PHP: Hypertext Preprocessor (recursive acronym). Created by Rasmus Lerdorf in 1994.
🏷️ PHP Tags

PHP code must be enclosed in special tags. The parser looks for these opening/closing tags to identify PHP code blocks.

<?php echo "Hello, World!"; ?>

Default / Standard tag — most commonly used. Always works regardless of PHP configuration.

<? echo "Hello, World!"; ?>

Short open tag — requires short_open_tag = On in php.ini. Not recommended for portability.

<script language="php"> echo "Hello, World!"; </script>

HTML script tag — embeds PHP using the HTML script element with language="php" attribute.

📝 Exam Point — 3 types of PHP tags 1) <?php ... ?> (Default)   2) <? ... ?> (Short)   3) <script language="php"> ... </script>
📦 Variables in PHP

A variable is a named storage location that holds a value which can change during program execution.

Rules for PHP Variables

  • All variables start with a dollar sign ($)
  • Variable name must start with a letter or underscore (not a digit)
  • Can contain letters, digits, and underscores
  • Case-sensitive: $Name and $name are different variables
  • No type declaration needed — PHP determines type automatically
<?php $name = "Balu"; // String variable $age = 30; // Integer variable $price = 99.50; // Float variable $is_admin = true; // Boolean variable ?>

📢 Echo Statement

The echo statement is used to output one or more strings to the browser.

Functions

Built-in functions · User-defined functions · Parameters & Arguments

🔧 What is a Function?

A function is a self-contained block of code designed to perform a specific task. You define it once and call it multiple times — avoiding repetition.

💡 Analogy A function is like a recipe. You write the recipe once (define the function). Whenever you want to cook that dish (call the function), you follow the same steps. You can even make it differently by using different ingredients (parameters).

Two types of functions in PHP:

TypeDescriptionExample
Built-inPre-defined by PHPstrlen(), strtoupper()
User-definedCreated by the programmerfunction greet() { ... }
📦 Built-in Functions

PHP has thousands of built-in functions. Here are common string functions:

FunctionPurposeExample
strlen()Length of stringstrlen("Hello") // 5
strtoupper()Convert to uppercasestrtoupper("hello") // HELLO
strtolower()Convert to lowercasestrtolower("HELLO") // hello
str_replace()Replace in stringstr_replace("a","b","cat") // cbt
substr()Part of stringsubstr("Hello",1,3) // ell
✍️ User-defined Functions

Syntax:

function functionName() { // code to execute }

Function without parameters:

function printGreeting() { echo "Hello, world!"; } printGreeting(); // Call the function // Output: Hello, world!

Function with parameters:

function greet($name) { echo "Hello, $name!"; } greet("Kumar"); // Output: Hello, Kumar! greet("Priya"); // Output: Hello, Priya!

Function with multiple parameters:

function addNumbers($x, $y) { echo $x + $y; } addNumbers(10, 40); // Output: 50
📝 Exam Point — Parameters vs Arguments Parameter: Variable in the function definition → function greet($name)
Argument: Actual value passed when calling the function → greet("Kumar")

📦 What is an Array?

An array is a variable that can store multiple values in a single variable name. Each value is accessed using an index (number or string key).

💡 Analogy An array is like a row of lockers in school. Each locker has a number (index). You can store one item in each locker, and access any item by its locker number.

Control Structures

if · if-else · if-elseif-else · switch · for · while · do-while · foreach

🔀 Conditional Statements

if Statement

Executes a block of code only if the condition is true.

$x = 10; if ($x > 5) { echo "x is greater than 5"; } // Output: x is greater than 5

if-else Statement

Executes one block if condition is true, another block if false.

$x = 3; if ($x > 5) { echo "x is greater than 5"; } else { echo "x is not greater than 5"; } // Output: x is not greater than 5

if-elseif-else Statement

Tests multiple conditions in sequence.

$x = 12; if ($x > 20) { echo "x is greater than 20"; } elseif ($x > 15) { echo "x is greater than 15 but not greater than 20"; } elseif ($x > 10) { echo "x is greater than 10 but not greater than 15"; } else { echo "x is not greater than 10"; } // Output: x is greater than 10 but not greater than 15

switch Statement

Tests a variable against multiple values. Uses break to stop execution, default as fallback.

$x = 10; switch ($x) { case 5: echo "x is equal to 5"; break; case 10: echo "x is equal to 10"; break; case 15: echo "x is equal to 15"; break; default: echo "x is not equal to 5, 10, or 15"; } // Output: x is equal to 10
⚠️ Important: break keyword Without break, execution "falls through" to the next case. Always use break at the end of each case unless fall-through is intentional.
🔄 Loops

for Loop

Entry-controlled loop. Used when the number of iterations is known. Checks condition before executing the body.

Syntax: for(initialization; condition; update) { body }

for ($i = 1; $i <= 5; $i++) { echo $i . "<br>"; } // Output: 1 2 3 4 5
for ($i = 5; $i >= 1; $i--) { echo $i . "<br>"; } // Output: 5 4 3 2 1

while Loop

Entry-controlled loop. Checks condition before each iteration. May never execute if condition is initially false.

$i = 1; while ($i <= 5) { echo $i . "<br>"; $i++; } // Output: 1 2 3 4 5
💡 while vs for Use while when you don't know in advance how many times to loop (e.g., reading until end of file). Use for when you know the exact count.

do-while Loop

Exit-controlled loop. Executes the body first, then checks the condition. Always executes at least once.

$i = 1; do { echo $i . "<br>"; $i++; } while ($i <= 5); // Output: 1 2 3 4 5
📝 Exam Point — do-while vs while do-while always executes at least once even if condition is false from the start.
while may never execute if condition is false initially.

foreach Loop

Designed specifically for iterating over arrays.

$array = array(1, 2, 3, 4, 5); foreach ($array as $value) { echo $value . "<br>"; } // Output: 1 2 3 4 5
$array = array("a" => 1, "b" => 2, "c" => 3); foreach ($array as $key => $value) { echo $key . " => " . $value . "<br>"; } // Output: a => 1 // b => 2 // c => 3

📝 HTML Forms with PHP

PHP can collect data submitted through HTML forms using the superglobal arrays $_POST and $_GET.

HTML Form (form.html):

<form action="process.php" method="post"> Name: <input type="text" name="name"> Email: <input type="email" name="email"> <input type="submit" value="Submit"> </form>

PHP Processing (process.php):

<?php $name = $_POST["name"]; $email = $_POST["email"]; echo "Name: " . $name; echo "Email: " . $email; ?>
⚖️ GET vs POST
Feature$_GET$_POST
Data visible?Yes (in URL)No (hidden)
Max data size~2000 charsNo limit
Bookmarkable?YesNo
Use caseSearch, filterForms, login, passwords
SecurityLess secureMore secure
📝 Exam Point Use POST for sensitive data (passwords, personal info). Use GET for non-sensitive data (search terms, page numbers).
📁 File Handling in PHP

PHP provides functions to read from and write to files on the server.

Key file functions:

FunctionPurpose
fopen(filename, mode)Opens a file
fread(file, length)Reads from an open file
fwrite(file, text)Writes to an open file
fclose(file)Closes an open file
filesize(filename)Returns file size in bytes

File Modes:

ModeMeaning
rRead only, from beginning
wWrite only, truncates file
aAppend — writes to end
r+Read and write

Reading a file:

<?php $myfile = fopen("Student.txt", "r") or die("Unable to open file!"); echo fread($myfile, filesize("Student.txt")); fclose($myfile); ?>

Writing to a file:

<?php $myfile = fopen("Student.txt", "w") or die("Unable to open file!"); $txt = "John Doe\n"; fwrite($myfile, $txt); fclose($myfile); ?>
🗄️ PHP with MySQL

PHP connects to MySQL databases using the MySQLi extension (available since PHP 5.0).

Key MySQL functions:

FunctionPurpose
mysqli_connect(host, user, pass, db)Opens database connection
mysqli_query(conn, sql)Executes SQL query
mysqli_fetch_array(result)Fetches result row as array
mysqli_num_rows(result)Returns number of rows
mysqli_close(conn)Closes connection

Connecting to MySQL:

<?php $servername = "localhost"; $username = "root"; $password = ""; $DB_name = "students"; $conn = mysqli_connect($servername, $username, $password, $DB_name); if (!$conn) { die("Connection failed: " . mysqli_connect_error()); } echo "Connected successfully"; ?>

Running a Query:

$sql = "SELECT * FROM students"; $result = mysqli_query($conn, $sql); while ($row = mysqli_fetch_array($result)) { echo $row['name'] . " - " . $row['email']; } mysqli_close($conn);
📝 Exam Point — MySQLi MySQLi = MySQL Improved. Available since PHP 5.0. Use mysqli_connect() to connect, mysqli_query() to execute SQL, mysqli_close() to disconnect.
