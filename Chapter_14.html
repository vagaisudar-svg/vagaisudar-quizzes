14.1 Introduction

Python and C++ are both general-purpose programming languages, yet they differ significantly:

S.NoPythonC++
1Typically an interpreted languageTypically a compiled language
2Dynamically typed languageStatically typed language
3Data type not required while declaring a variableData type required while declaring a variable

💡 Glue Language

These two languages complement one another perfectly. Python is mostly used as a scripting or "glue" language — the top-level program mostly calls routines written in C or C++. This is useful when the logic can be written in terms of existing C++ code that can be called and manipulated through a Python program.

14.2 Scripting Language

A scripting language is a programming language designed for integrating and communicating with other programming languages. Some of the most widely used scripting languages are:

JavaScript, VBScript, PHP, Perl, Python, Ruby, ASP, and Tcl

Since a scripting language is normally used in conjunction with another programming language, they are often found alongside HTML, Java, or C++.

Basically, all scripting languages are programming languages. The theoretical difference is that scripting languages do not require a compilation step — they are interpreted. 14.3 Applications of Scripting Languages

  1. To automate certain tasks in a program
  2. Extracting information from a data set
  3. Less code intensive as compared to traditional programming languages
  4. Can bring new functions to applications and glue complex systems together
✅ About Python

Python is an interpreted, high-level, general-purpose programming language that can be used on any modern computer operating system. It processes text, numbers, images, scientific data, and more. Nowadays, large applications are written almost exclusively in Python.

14.4 Features of Python over C++

  • Python uses Automatic Garbage Collection whereas C++ does not.
  • C++ is a statically typed language, while Python is a dynamically typed language.
  • Python runs through an interpreter, while C++ is pre-compiled.
  • Python code tends to be 5 to 10 times shorter than equivalent C++ code.
  • In Python, there is no need to declare types explicitly — in C++ this is required.
  • In Python, a function may accept an argument of any type and return multiple values without declaration. In C++, a return statement can return only one value.
📌 Garbage Collection

Python deletes unwanted objects (built-in types or class instances) automatically to free memory. The process by which Python periodically frees and reclaims blocks of memory no longer in use is called Garbage Collection.

14.5.1 MinGW Interface

MinGW refers to a set of runtime header files used in compiling and linking the code of C, C++, and FORTRAN to run on Windows Operating System.

MinGW-W64 (a version of MinGW) is the best compiler for C++ on Windows. To compile and execute a C++ program, you need g++ for Windows. MinGW allows compiling and executing C++ programs dynamically through Python using g++.

💡 g++ explained

g++ is a program that calls GCC (GNU C Compiler) and automatically links the required C++ library files to the object code.

14.6 Python Program to Import C++

Python contains many modules. Since our program is an integration of two different languages, we must import modules like os, sys, and getopt.

14.6.1 Module

Modular programming is a software design technique to split your code into separate parts called modules. The focus is on minimizing dependencies between modules.

A module is a file containing Python statements and definitions. For example, a file factorial.py is a module whose function name is fact(). We use modules to break down large programs into small, manageable, organized parts and to enable code reusability.

Example: factorial.py
def fact(n):
    f = 1
    if n == 0:
        return 0
    elif n == 1:
        return 1
    else:
        for i in range(1, n+1):
            f = f * i
        print(f)
>>> fact(5)
120

14.6.2 How to Import Modules in Python

We can import definitions from a module into another using the import keyword:

>>> import factorial

The dot (.) operator is used to access the functions defined inside the module:

>>> factorial.fact(5)
120

14.6.2.1 — sys module and sys.argv ▼

The sys module provides access to built-in variables used by the interpreter. One such variable is argv.

sys.argv is the list of command-line arguments passed to the Python program. argv holds all items that come via command-line input.

  • sys.argv[0] — contains the name of the Python program (e.g., pali.py)
  • sys.argv[1] — the next argument passed (here it is the C++ file)
main(sys.argv[1:])

The input C++ file is sent along with its path as a list using argv[1]. argv[0] contains the Python program which need not be passed because by default __main__ contains the source code reference.

14.6.2.2 — os module and os.system() ▼

The os module in Python provides a way of using operating system dependent functionality. It allows you to interface with the Windows operating system.

os.system() executes the C++ compiling command — a string containing a Unix/C command (which also supports C++ commands) in the shell (Command Window).

Syntax
os.system('g++ ' + <variable_name1> + ' -o ' + <variable_name2>)
PartMeaning
os.systemFunction defined in os module to interact with the operating system
g++General compiler to compile C++ program under Windows
variable_name1Name of the C++ file along with its path and without extension (string format)
-oSpecifies output mode; output prefix with hyphen
variable_name2Name of the executable file without extension (string format)
Example
os.system('g++ ' + cpp_file + ' -o ' + exe_file)
📌 Note

The '+' in os.system() indicates string concatenation. Give a space after each word — e.g., 'g++ ' (with trailing space) to ensure correct command formation.

14.6.2.3 — getopt module ▼

The getopt module helps you parse (split) command-line options and arguments. It provides the getopt() method for command-line argument parsing.

Syntax
opts, args = getopt.getopt(argv, options, [long_options])
ParameterExplanation
argvThe argument list to be parsed (split). In our program, the complete command is passed as a list: e.g., c:\pyprg\pali.py -i c:\pyprg\pali_cpp
optionsString of option letters the program recognises (like 'i' or 'o'). Options followed by a colon (:) denote a mode argument.
long_optionsList of strings. Long option arguments must be followed by an equals sign =. The C++ filename along with its path is passed as string; 'i' is passed to indicate it as the input file.

getopt() returns two elements:

  • opts — list of (option, value) tuples: e.g., [('-i', 'c:\\pyprg\\p4')]
  • args — error string; empty list [] if no error
Example
opts, args = getopt.getopt(argv, "i:", ['ifile='])

Here: opts = [('-i', 'c:\\pyprg\\p4')] and args = [] (no error)

>>> print(args)
[]
__name__ Special Variable ▼
if __name__ == '__main__':
    main(sys.argv[1:])

Since there is no main() function in Python, when the interpreter runs a program, code at level 0 indentation is executed first. Before doing that, the interpreter defines special variables.

__name__ is one such variable — it stores the name of the current Python file. If the source file is executed as the main program, the interpreter sets __name__ to "__main__".

When the condition if __name__ == '__main__': is true, the main() function is called.

📌 Note

sys.argv[1:] — gets everything after the script name (file name). sys.argv[0] is the script name (Python program). Remember string slicing from Chapter 8.

Example 14.7.1 — C++ Palindrome Program

pali_cpp.cpp
/* To check whether the number is palindrome or not using while loop. */
// Now select File->New in Notepad and type the C++ program
#include <iostream>
using namespace std;
int main()
{
    int n, num, digit, rev = 0;
    cout << "Enter a positive number: ";
    cin >> num;
    n = num;
    while(num)
    {
        digit = num % 10;
        rev = (rev * 10) + digit;
        num = num / 10;
    }
    cout << "The reverse of the number is: " << rev << endl;
    if (n == rev)
        cout << "The number is a palindrome";
    else
        cout << "The number is not a palindrome";
    return 0;
}
// Save this file as pali_cpp.cpp
pali.py — Python program to compile and execute pali_cpp.cpp
# Now select File->New in Notepad and type the Python program
# Save the File as pali.py
# Program that compiles and executes a .cpp file
# Python c:\pyprg\pali.py -i c:\pyprg\pali_cpp
import sys, os, getopt

def main(argv):
    opts, args = getopt.getopt(argv, "i:")
    for o, a in opts:
        if o in "-i":
            run(a)

def run(a):
    inp_file = a + '.cpp'
    exe_file = a + '.exe'
    os.system('g++  ' + inp_file + '  -o  ' + exe_file)
    os.system(exe_file)

if __name__ == '__main__':
    main(sys.argv[1:])

The variable inp_file stores the C++ file with its extension; exe_file stores the executable file with .exe. Because the file extensions are added by the Python script, it is even possible to execute C programs this way.

14.8 How Python Handles Errors in C++

Python not only executes successful C++ programs — it also displays errors if any occur during C++ compilation.

3. What is the purpose of sys, os, getopt modules in Python? ▼

sys module: Provides access to built-in variables used by the interpreter, including sys.argv — the list of command-line arguments passed to the program.

os module: Provides a way to use operating system dependent functionality. The os.system() function executes shell commands — used here to run g++ to compile C++ files and then execute the resulting .exe file.

getopt module: Helps parse (split) command-line options and arguments. The getopt.getopt() function splits the command into options (opts) and any leftover arguments (args), making it easy to handle flags like -i and associated values.

4. Write the syntax for getopt() and explain its arguments and return values ▼
opts, args = getopt.getopt(argv, options, [long_options])

argv — the argument list to be parsed. In the program, the complete command line is passed as a list.

options — string of option letters the program recognises. Options followed by a colon (:) require an argument. Example: "i:"

long_options — list of strings for long options; long options needing arguments must be followed by =. Example: ['ifile=']

Return values:
• opts — list of (option, value) tuples: e.g., [('-i', 'c:\\pyprg\\p4')]
• args — empty list [] if no error; contains error string otherwise
